# TrainMasterApi

## Descrição do Projeto

TrainMasterApi é uma API robusta desenvolvida para gerenciamento e controle de treinos. A aplicação oferece funcionalidades completas para criar, organizar e acompanhar programas de treinamento, permitindo aos usuários monitorar seu progresso e otimizar seus resultados.

### Características Principais

- ✅ Gerenciamento de treinos
- ✅ Acompanhamento de progresso
- ✅ Controle de exercícios
- ✅ Registro de séries e repetições
- ✅ Análise de desempenho
